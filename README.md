# Prates Hub

Central de aplicativos para Windows x64. [Baixar a versão mais recente](https://github.com/Pr4Tes/prates-hub-releases/releases/latest).

Baixe o ZIP, extraia e abra PratesHub.exe. O .NET já acompanha o pacote. Windows 10 x64 ou mais recente; Cam Lite exige Windows 11.

Reúne YT Downloader, Cam Lite e Prates LAN. Adicione seus outros programas pelo botão Adicionar programa; organize com busca, categorias e favoritos.

As atualizações oficiais dos apps Prates e do Hub são verificadas por assinatura RSA e SHA-256. A consulta pode ser automática ao abrir; cada instalação pede confirmação.

Remover só do Hub preserva o aplicativo e permite restaurar a entrada. Desinstalar do PC usa o desinstalador do Windows ou remove somente os executáveis portáteis registrados pelo Hub. A cada desinstalação, escolha preservar ou apagar as configurações conhecidas. O Hub preserva vídeos, documentos, backups exportados e arquivos desconhecidos. Para terceiros, use as opções do desinstalador oficial.

Este repositório distribui os binários e manifestos assinados. O catálogo do usuário permanece local. Licenças do runtime e instruções estão dentro do ZIP e nos arquivos da versão.
