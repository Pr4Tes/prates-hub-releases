# Prates Hub

Central de aplicativos para Windows x64. [Baixe a versão mais recente](https://github.com/Pr4Tes/prates-hub-releases/releases/latest).

## Versão 1.3.0

Biblioteca mais limpa: ícone, nome, categoria, estado e ação principal. Clique no nome para ver descrição, versões, origem, novidades e gerenciamento.

- Instalação em lote com seleção e revisão antes de iniciar a fila.
- Adicionar por link do repositório GitHub, com escolha do instalador Windows e revisão da fonte.
- Consultas ao abrir, diariamente ou semanalmente. A agenda funciona com o Hub aberto e ao reabri-lo; não existe serviço ativo após fechar o Hub. A instalação sempre pede confirmação.
- Melhor legibilidade, botões maiores e nomes acessíveis. Tab navega, Enter abre os detalhes pelo nome e Ctrl+F busca.

Use o Setup para instalar por usuário ou extraia o ZIP e abra PratesHub.exe. O .NET acompanha o pacote. Windows 10 x64 ou mais recente; Cam Lite exige Windows 11.

O catálogo inicial reúne YT Downloader, Cam Lite e Prates LAN. Inclui atualizar todos, reparo, downloads com progresso, pausa e cancelamento, histórico e backup do catálogo. Para usar backup no Drive, escolha uma pasta sincronizada pelo Google Drive para Desktop.

Terceiros exigem release estável, instalador compatível EXE/MSI, correspondência única e SHA-256 publicado. As telas dos fornecedores podem aparecer. Reinício pendente ou instalação não confirmada interrompem a fila.

Remover só do Hub preserva o aplicativo e permite restaurar a entrada. Desinstalar do PC usa o desinstalador do Windows ou portáteis registrados pelo Hub. Escolha preservar ou apagar configurações conhecidas. Vídeos, documentos, backups e arquivos desconhecidos são preservados.

Atualizações Prates e do próprio Hub usam manifestos assinados e SHA-256. Catálogos anteriores são preservados. Código do proprietário em repositório privado; dados pessoais não acompanham a entrega pública. Licenças, notas e hashes estão nos anexos.
